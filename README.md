# StarPets Adopt Me Price Overlay

Оверлей для **Adopt Me (Roblox)**, который показывает **актуальные цены питомцев и предметов** с сайта **StarPets** прямо в игре: у питомцев в инвентаре и в окне трейда, а также считает **выгоду/невыгоду трейда**.

Работает через инжектор **Xeno** — игроку нужен только сам скрипт, ничего ставить не надо.

---

## 🚀 Быстрый старт (для игрока)

1. Открой **Adopt Me** в Roblox и зайди на сервер.
2. Открой инжектор **Xeno** и подключись к процессу Roblox.
3. Вставь в консоль Xeno одну строку:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/bynicL/starpets-adoptme-overlay/refs/heads/main/overlay.lua"))()
```

4. Нажми Execute. Готово ✅
   - Цены появятся в **левом нижнем углу** каждого слота с питомцем/предметом (без фоновой полосы).
   - Сверху справа — панель **⚙️ Настройки** (можно сворачивать и переключать: цены на слотах / стоимость рюкзака / панель трейда).
   - При открытии инвентаря показывается **общая стоимость рюкзака**.
   - При открытии трейда — панель **анализа трейда**: сумма твоя / партнёра и **общая выгода или невыгода**.

---

## ✨ Возможности

- 🏷️ **Цены на всех питомцах и предметах** (слота в инвентаре, окно трейда).
- 🎯 **Актуальные цены** — берутся с сайта StarPets, **минимум по всем возрастам** (пет единой ценой), каждое обновление — свежие данные.
- 🤖 **Автоматическое сопоставление** иконок игры с ценами сайта — по полной базе Adopt Me, без ручных списков.
- 🧮 **Выгода/невыгода трейда**: панель показывает суммы обеих сторон и чёткую надпись «ВЫГОДНО +X₽» / «НЕВЫГОДНО -X₽» / «РАВНО».
- 🎒 **Общая стоимость рюкзака** при открытии инвентаря.
- ⚙️ **Панель настроек**: вкл/выкл цены, стоимость рюкзака, панель трейда.
- ⚡ Мгновенный скан по событиям (без ручного обновления).
- 📊 Цены обновляются **автоматически** через GitHub Actions (раз в час) — игроку ничего не нужно.

---

## 🔄 Как обновляются цены (для владельца репозитория)

Цены собираются с API StarPets и встраиваются в `overlay.lua` автоматически через GitHub Actions:

1. `parser3.py` — скачивает актуальные цены с сайта StarPets (минимальные по возрасту для каждого питомца/масти).
2. `merge.py` — сопоставляет иконки игры (база `adoptme_pets_final.json` + `adoptme_items.json`) с ценами сайта.
3. `generate_lua.py` — встраивает свежие цены в `overlay.lua` между маркерами `=====BEGIN_PRICES=====` / `=====END_PRICES=====`.

Workflow `.github/workflows/update-prices.yml` запускается **каждый час** и автоматически коммитит изменения. Игрок, повторно выполнив `loadstring`, получает свежие цены.

> **Важно:** `overlay.lua` — это генерируемый файл. Не правь его вручную между маркерами цен, иначе следующая автогенерация перезатрёт правки.

## 🗂 Структура репозитория

| Файл | Назначение |
|---|---|
| `overlay.lua` | **Публичная версия скрипта** (логика + встроенные цены) — именно её запускает игрок через loadstring |
| `adoptme_pets_final.json` | Полная база питомцев Adopt Me (id + иконка + имя) |
| `adoptme_items.json` | Полная база предметов Adopt Me (зполья, транспорт, игрушки) |
| `parser3.py` | Парсер цен с StarPets |
| `merge.py` | Сопоставление базы игры с ценами сайта |
| `generate_lua.py` | Встраивание цен в overlay.lua |
| `.github/workflows/update-prices.yml` | Автообновление цен (каждый час) |

---

## 🧩 Технические детали

- **Сопоставление:** база `adoptme_pets_final.json`/`adoptme_items.json` связывает `rbxassetid` иконки в игре ↔ имя на сайте StarPets. Несопоставленные (нет цены на сайте) скрипт просто не показывает — без мусорных «?» у не продаваемых предметов.
- **Цена** — минимальная по всем возрастам питомца (например newborn → full grown), также учитываются Neon/Mega/Fly/Ride как отдельные состояния.
- **Безопасность:** скрипт только читает цены и рисует GUI-метки; ничего не отправляет на сервер, не трогает аккаунт.

---

## ⚠️ Примечание

- Скрипт предназначен для **исследовательских целей** и личного использования. Использование оверлеев в Adopt Me — на твоё усмотрение и риск.
- Не весь контент имеет цены на StarPets (например, некоторые старые яйца/предметы не продаются) — для них цена не отображается.
